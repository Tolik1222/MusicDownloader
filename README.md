Повнофункціональний бот для завантаження музики з SoundCloud з підтримкою Telegram-бота та веб-інтерфейсу. Проект поєднує зручність мобільного месенджера та потужність веб-додатку з адмін-панеллю.

## Що реалізовано

### Telegram Bot
- **Пошук треків** — надішліть назву пісні або виконавця
- **Прямі посилання** — скиньте URL з SoundCloud для миттєвого завантаження
- **Пагінація результатів** — зручна навігація по результатах пошуку (5 треків на сторінку)
- **Прогрес-бар завантаження** — візуальне відстеження процесу (25%, 50%, 75%, 99%)
- **Автоматична конвертація** — всі треки конвертуються в MP3 192kbps
- **Статистика** — команда `/stats` для адміністраторів

### Веб-інтерфейс
- **Telegram Login** — авторизація через Telegram Widget
- **Пошук треків** — повнотекстовий пошук з пагінацією
- **Історія завантажень** — особиста історія кожного користувача (останні 20 треків)
- **Завантаження через браузер** — альтернатива боту для веб-користувачів
- **Адаптивний дизайн** — коректна робота на мобільних пристроях

### Адмін-панель
- **Загальна статистика** — кількість користувачів та завантажень
- **Усі завантаження** — історія з фільтрацією (останні 300 записів)
- **Список користувачів** — перегляд активності кожного юзера
- **Топ-10 треків** — найпопулярніші завантаження
- **Графіки активності** — завантаження та реєстрації по днях (30 днів)
- **Видалення записів** — модерація історії завантажень

## Технологічний стек

### Backend
- **Python 3.11+**
- **Quart** — асинхронний веб-фреймворк (async Flask)
- **aiogram 3.x** — сучасна бібліотека для Telegram Bot API
- **yt-dlp** — завантаження та обробка аудіо
- **aiosqlite** — асинхронна робота з базою даних

### Інфраструктура
- **SQLite + WAL mode** — швидка база даних з підтримкою конкурентності
- **FFmpeg** — конвертація аудіо в MP3
- **Threading** — паралельний запуск бота та веб-сервера
- **LRU Cache** — кешування результатів пошуку (200 записів)


## Швидкий старт (локально)

### 1. Встановіть залежності

```
pip install -r requirements.txt
```

Також потрібен **FFmpeg**:
- **Linux**: `sudo apt install ffmpeg`
- **macOS**: `brew install ffmpeg`
- **Windows**: завантажте з [ffmpeg.org](https://ffmpeg.org/download.html)

### 2. Створіть `.env` у корені проєкту

```env
TELEGRAM_TOKEN=your_bot_token_from_botfather
SECRET_KEY=your_random_secret_key_for_sessions
BOT_USERNAME=YourBotUsername
ADMIN_IDS=123456789,987654321
PORT=10000
```

### 3. Отримайте Telegram Bot Token

1. Напишіть [@BotFather](https://t.me/BotFather) у Telegram
2. Виконайте `/newbot` і дотримуйтесь інструкцій
3. Скопіюйте токен у `.env`
4. Налаштуйте Telegram Login Widget через `/setdomain` (вкажіть ваш домен)

### 4. Запустіть проект

```
python app.py
```

Бот працюватиме у режимі **Polling**, веб-інтерфейс — на `http://localhost:10000`

## База даних

Проект використовує **SQLite з WAL режимом** для підтримки конкурентних записів.

### Таблиці:

**`users`** — інформація про користувачів
```sql
user_id    INTEGER PRIMARY KEY
username   TEXT
first_name TEXT
join_date  DATETIME
```

**`history`** — історія завантажень
```sql
id            INTEGER PRIMARY KEY AUTOINCREMENT
user_id       INTEGER (FK → users)
track_title   TEXT
track_url     TEXT
download_date DATETIME
```

### Автоматична ініціалізація

База створюється автоматично при першому запуску через `DB.init_db()`.

## Бізнес-логіка

### Робота бота (Telegram)
1. Користувач надсилає текст або посилання
2. Якщо посилання — прямо завантажує трек
3. Якщо текст — виконує пошук через `scsearch` (yt-dlp)
4. Результати виводяться з кнопками (макс. 5 на сторінку)
5. Після вибору — трек завантажується, конвертується в MP3 та надсилається
6. Запис додається в історію (`history` таблиця)

### Робота веб-інтерфейсу
1. Користувач авторизується через Telegram Login Widget
2. HMAC-SHA256 перевірка підпису від Telegram
3. Дані зберігаються у сесії (Flask-session)
4. Пошук працює аналогічно боту
5. Завантажені MP3 надсилаються через `send_file()`

### Адмін-панель
- Доступна тільки користувачам з `ADMIN_IDS`
- Використовує декоратор `@admin_required`
- Відображає дані через SQL-запити (`DB.admin_*` функції)
- AJAX-видалення записів (`/admin/delete/<id>`)

### Автоочищення файлів
- Фоновий потік видаляє всі файли з `downloads/` кожні 10 хвилин
- Запобігає переповненню диска на сервері
- Після надсилання файлу в Telegram він одразу видаляється

## Відомі обмеження

1. **yt-dlp може ламатися** після оновлень SoundCloud — періодично потрібно оновлювати `yt-dlp`
2. **Відсутній rate limiting** — користувач може спамити завантаженнями
3. **Одна база SQLite** — не підійде для великого навантаження (>1000 одночасних користувачів)
4. **Немає черги завантажень** — якщо 10 користувачів одночасно завантажують, yt-dlp може не встигнути
5. **Telegram Bot API обмеження** — макс. 50 МБ на файл (довгі треки можуть не надіслатися)
